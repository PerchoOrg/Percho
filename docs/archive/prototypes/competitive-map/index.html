Percho — Competitive Map

谁在做"move 之前的决策"和"move 之后的基础设施"。按赛道分类,标记定位、模式、对 Percho 的相关性。
pre-move post-move SEO/content marketplace B2B subscription

Pre-move decision — 主流玩家 SEO/内容站已占位

"选城市 / 选社区"的决策工具。Niche 是 800lb gorilla,SEO 头部基本被吃干。数据驱动为主,无 agent 服务闭环。
Niche
niche.com
pre-moveSEO/contentrating
最大的"选社区/学校"站,年 UV 1亿+。学校+邻里评级+"Best Places to Live"榜单。变现=学校/大学广告 + agent lead。硬伤:数据死板、无真实照片、无 agent 服务。DR 85+,SEO 无法正面刚。
AreaVibes
areavibes.com
pre-moveSEO/content
Livability score 起家,量比 Niche 小一个量级。纯 SEO/广告模式。
Livability
livability.com
pre-moveSEO/contentmedia
内容站 + "Top 100 Best Places" 榜单。母公司 Journal Communications——是媒体,不是产品公司。
BestPlaces (Sperling's)
bestplaces.net
pre-movelegacy
老牌数据源, Money 杂志 "Best Places to Live" 榜单背后的数据。90 年代产物,UI 停留在 2005。
Teleport → Topia
topia.com
pre-moveB2Bexit
早期"帮 remote worker 选城市",2017 被 Topia 收购,转 B2B relocation SaaS。对 Percho 的信号:C 端 relocation 决策工具最好的 exit 是被 B2B relocation SaaS 收编。

Pre-move decision — 新一代 / 更贴 Percho 窄客群 + 订阅制

远程工作者、数字游民、投资角度切入的选城市工具。客群窄但客户愿付费。
Nomad List
nomadlist.com
pre-movesubscriptioncommunity
数字游民选城市,全球 vibe/成本/wifi/安全评分 + 社区。$99/年会员 $2-3M ARR。证明:"选城市"愿付费的用户存在,但客群非常窄。
Home.LLC
home.llc
pre-movedatainvestment
数据驱动"哪个 zip code 该买",偏投资视角。
Ownwell
ownwell.com
pre-movedata
同类数据驱动房产决策工具,偏 property tax / 投资侧。
Movley
movley.com
pre-moveconcierge
帮人 relocate 的 concierge 服务,人工重,不是 tech-driven。
r/SameGrassButGreener
reddit.com/r/SameGrassButGreener
pre-moveUGC
450k+ 用户,"我该搬到哪个城市" 的默认问答池。决策最前期流量在这里,Niche/Percho 都接不到。

Post-move infrastructure 分散,C 端品牌位空着

搬家后 3-6 个月的生活基础设施重建。Updater 融资 $200M+ 但走 B2B 分销,C 端品牌位子空着。
Updater
updater.com
post-moveB2Bunicorn
跟 property manager / agent 合作,搬家时一键办水电煤 + 改地址 + 搬家公司。融资 $200M+,估值 ~$700M。最像"post-move 变现平台",但藏在 B2B 分销后,用户不认识它。
MoveEasy
moveeasy.com
post-moveB2B
Updater 的直接对手,也是 B2B 分销模式。
Porch
porch.com
post-movemarketplacepublic
Home services marketplace(搬家/装修/清洁/家电安装)。上市 $PRCH,市值缩水 90%,业务艰难但活着。
Thumbtack
thumbtack.com
post-movemarketplace
通用 home services marketplace,不专做 relocation。
Angi
angi.com
post-movemarketplace
通用 home services,前身 Angie's List + HomeAdvisor 合并。
TaskRabbit
taskrabbit.com
post-movemarketplace
按需劳动力,IKEA 组装 / 搬家杂活。IKEA 收购。
HomeAdvisor
homeadvisor.com
post-movelead-gen
装修 lead gen,Angi 母公司旗下。

房源 / 大盘玩家 决策后期流量已被吃

列房源 + agent 分佣的巨头。Percho 不打这个战场,但它们是变现路径的最终节点。
Zillow
zillow.com
pre-movepost-movemarketplace
房源 + Premier Agent 分佣。5000+ 人。agent 端满意度暴跌(Premier Agent 涨价 + Flex 抽 40%),agent 有替代平台意愿。
Redfin
redfin.com
marketplacebrokerage
房源 + 自营经纪。SEO "Best places to live" 前 10 占位者之一。
Airbnb
airbnb.com
pre-movethreat
长租/试住基础设施。威胁:如果认真做 "long-stay relocation",他们有流量+住宿+社区,Percho 的 pre-move 决策位直接被吃。
Furnished Finder
furnishedfinder.com
rentaltry-before-buy
中长期带家具租赁,travel nurse 起家。"试住后买" 的天然入口。
Blueground
blueground.com
rentaltry-before-buy
高端 furnished long-stay,relocation 用户的天然试住供给。

Percho 这里

Percho
percho.co
pre-movemarketplaceagent-in-loop
定位空位:Niche 无 agent、Zillow 不选社区、Nomad List 全球太宽、Updater 藏在 B2B——中间的 "agent-in-the-loop 的真实社区决策" 位置空着。Unfair advantage 目前只有一条:笑云 + Atlanta 深度。其他一切(swipe UX、真实照片、subdivision 数据)都是可复制功能。
3 个空白区可能是机会:
① Pre-move 决策链里 "agent-in-the-loop" 的位置 (Niche 无 agent, Zillow 不选社区) —— Percho 现在的战场
② Post-move 的 C 端品牌位 (Updater 走 B2B, C 端认知空白) —— 有流量后的自然延伸
③ 决策最前期 "要不要搬 / 搬哪个州" 的 UGC 流量目前在 Reddit r/SameGrassButGreener,没人做产品化

2 个真威胁: Airbnb 认真做 long-stay relocation,或 ChatGPT/Perplexity 直接回答 "我该搬到哪"。
