Agent 的小区影片 · 第二版

对着这两天 app 的改动重想之后，和第一版比，变了五处。Agent 上传素材的那四步（拖进照片视频、勾授权、看镜头表、发布）不变，这里不再重画。

画面里的界面文字是英文。图取自现在 Edinburgh 的影片，小区名 Laurel Springs、agent 的名字和卡上的数字都只是示意。橙色虚线框是新增的东西，真实页面里没有虚线。

第一版哪里错了：我说 agent 的版本只放在他的链接上、app 不用动。但分享链接会直接打开 app，装了 app 的买家点进来看到的是 Percho 的片，agent 的版本和名片都不见了。见下面第二节。

后台里 agent 看到的：打开一个没片的小区，My film 最上面写着 "This neighbourhood has no film yet. Yours will be the one buyers see in the app."

已经有 Percho 片的 20 个小区不变：app 里还是 Percho 的片，他的版本是另外一部。

同一个小区来了第二个 agent：先到先得，第二位的版本只在他自己的链接上。

周边的学校、公园、商店：没片的小区我们手里没有现成素材，要自动找一遍。每个小区花多少钱我还没有数，先跑一个量出来再报给你。

3给 agent 看他的片有多少人看

爱心和大拇指朝下现在是明确的按键，app 也已经在往服务器回传操作记录。所以 My film 里可以给他一排数字，这是他继续补素材、继续转发的理由。其中"看了"和"看完"两项要跟着第二节那个 iOS 版本一起加上记录。下面的数字是示意。

Add material

质量保险：一部 agent 的片被点"不喜欢"的比例明显比别的片高，就自动从 app 里撤下来，回到我们这里人工看。这个数字不给 agent 看。

4素材按卡片的框来挑和裁

卡片左上角是地名，右上角四个按键，下面是小区名和署名。Agent 拍的东西如果主体正好在这些位置，就会被盖住。所以挑视频片段和裁照片时，主体要落在中间的白框里；每件素材的名字限制在左上角放得下的长度（大约 24 个字符）。

place name
four buttons
name · agent · pill
the subject stays in here
斜线是会被盖住的地方，白框是主体该在的地方。

需要你定

  1. 没片的小区，agent 的片看过之后直接当 app 里的片建议：是。这是补覆盖率最快的路。
  2. Agent 的链接在 app 里打开时放他的版本和名片建议：是。要发一个 iOS 版本。
  3. 首页卡上那行署名（with Dana Cole · Keller Williams）建议：要。这是 agent 肯做的原因，也只有一行。
  4. 第一版里另外三条不变素材也进 Percho 素材库并署名；每个 agent 每个小区一部，一天最多重剪一次；头一批人工看过才生效。
