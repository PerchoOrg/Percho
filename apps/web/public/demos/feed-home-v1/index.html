首页：滑动只管翻，喜欢点爱心

已经定了，app 已按此修改（2026-11-27）：左右滑、一次一部、要 ✕。

这一页有一处画错了：真实 app 里卡片右上角中间本来就是爱心（存起来时变红），不是下面画的书签。所以爱心没有搬到右下角，留在右上角那一排，只是多了"喜欢"的意思。那一排现在是四个按钮：静音、分享、不喜欢（一个向下的大拇指，不是 ✕）、爱心，爱心在最右边。左右两边都露出相邻卡片的边。下面的图和可以滑的手机保留原样作为记录，以 app 为准。

你提了两件事：一是新买家看到第一张卡不知道要干嘛，要不要像小红书那样排四个让他选，或者加一个演示动画；二是左右滑当"喜欢 / 不喜欢"不好使，滑走不一定是不喜欢。

我的看法：把第二件事改了，第一件事就基本解决了。买家不知所措，主要是因为"左右滑 = 表态"在看影片的 app 里没人见过。演示动画现在其实已经有一个（第一次打开时卡片自己往右、往左各晃一下），它没起作用，说明问题不在缺少演示，而在手势本身要人教。换成人人都会的"往上滑看下一个"，再让下一张露一条边，就不用教了。

所以我建议：首页仍然一次放一部影片，不改成四宫格；滑动只负责翻，可以翻回去；喜欢用爱心；不喜欢用一个小的 ✕。下面第一部分是一台能真滑的手机，可以直接试。

二、和现在比，变了五处

右边手机上的虚线框和数字是标注，真实 app 里没有。

  1. 滑动。现在：右滑是喜欢，左滑是不喜欢，滑走就回不来。改后：滑动只是翻到下一个或上一个，不算任何态度。
  2. 爱心。现在：右上角的小书签负责"存起来"，右滑负责"喜欢"，是两件事。改后：合成一个爱心，放大，放到右下角拇指够得着的地方。点亮 = 喜欢 = 存进 Saved。
  3. ✕。右上角书签原来的位置换成 ✕，意思是"这个不用再给我看"。卡片上的按钮数量没有变多。
  4. 下一张露一条边。现在首页只看得到一张卡，看不出后面还有。改后卡片底下露出下一张的边。
  5. 第一次打开的提示。现在：卡片自己往右、往左各晃一下。改后：一行字 Swipe up for the next place，滑过一次就消失。

不变的：点名字进 Explore 页、右下角的 Communities ›、上面的 Map、点画面暂停，都和现在一样。从 Communities › 点进去的那一页用同一套手势。

三、为什么我推荐上下滑，而不是左右滑

  • 往上滑看下一个是抖音、Instagram、YouTube 短视频和小红书视频共同的手势，买家手上已经会了，不用学。
  • 左右滑一张卡在很多人印象里是交友 app："左滑 = 不要"。你想去掉的正是这层意思，换成上下就没有了。
  • "向上滑表示不喜欢"我不建议：往上滑是所有人下意识的"下一个"，会记下大量并不是真心的不喜欢，等于把现在的问题换个方向留下来。不喜欢应该是一个要特意去点的按钮。

左右滑也能做，上面那台手机切到"左右滑"可以对比手感。

四、如果首页改成四宫格，会是这样

它的好处：一看就知道点哪里，买家自己挑。

我不建议用它做首页，三个原因：

  1. Percho 最打动人的是一打开影片就在放。四宫格里影片变成四张小图，第一眼和别的找房 app 没有区别。
  2. 现在一共 28 部影片（8 个城市、20 个社区）。四宫格滑三四下就到底，会显得内容很少；一次一部不会。
  3. 刚要搬来亚特兰大的买家不认识这些地名，光看名字和封面选不出来，影片放起来他才知道这是个什么地方。小红书的封面和标题本身就是内容，我们的封面只是一个地名。

"让买家自己选"这个好处，改后的首页也有：可以往回翻，可以点 Communities › 往下一层，也可以在 Search 里直接搜。

五、每个动作，Percho 记下什么

点亮爱心存进 Saved；以后多推相似的地方。
点 ✕这张不再出现；相似的少推。在 Search 和地图里仍然找得到。
只是滑过去不算喜欢，也不算不喜欢。其他的都看过之后，这张还会再出现。
看完整部影片、点名字进 Explore、点 Communities算"有点兴趣"，比爱心轻。

代价：特意点爱心的人会比顺手滑一下的人少得多，推荐会比现在学得慢。所以最后一行（看了多久、有没有点进去）要一起做，这是新增的工作。以前右滑喜欢过的记录都保留。

要你回复的

1. 滑动方向：上下，还是左右。我推荐上下。

2. 首页：一次一部影片，还是四宫格。我推荐一次一部。

3. ✕ 按钮：要，还是不要（不要的话卡上只有爱心）。我推荐要。

回一句"按推荐的"，或者比如"左右，一次一部，不要 ✕"就行。你回复之前我不改 app。
