全部在 Percho app 里完成

前三版都画在网页上，错了。这一版：agent 从开通、新建小区、传素材、看片、发布、看数字，到录头像和录旁白，全在 iPhone 的 Percho app 里，不需要打开任何网页。

界面文字是英文。图取自 Edinburgh 的影片，小区名、人名、数字都是示意。橙色虚线框是新增的东西。

买家看到的 app 不变。Agent 的东西都在 You 页里，只有开通了 agent 的账号才看得到。

You 页的 Account 下面多一行 I’m an agent。点进去填名字、公司、执照号，一次就好。之后这个账号的 You 页最上面多出 My films。

放进 app 之后，多出来的三件事

1. 付费要过苹果这一关。在 app 里卖数字功能，苹果一般要求走它的内购，要抽成。之前做好的 Stripe 那套不能直接在 app 里用。具体走内购还是别的方式，动手前我会把苹果现在的规则核对清楚再给你方案和费率。

2. 要发新版本，而且比平时大。App 现在没有选相册、录音、录像、推送通知这几样能力，都要新加，要向用户要相册、相机、麦克风、通知四个权限，苹果会审。

3. 账号里要有"agent"这个身份。现在 app 里注册的都是买家。开通 agent 是在现有账号上加身份，不用重新注册。

需要你定

  1. 入口和管理都在 You 页（Account 下一行开通；开通后最上面是 My films）建议：是。不加第五个底部标签。
  2. 新建方式：先选相册，由拍摄地点认小区，认不出再打名字建议：是。
  3. 开通时要执照号建议：要。不然任何人都能自称 agent 把片子放进 app。
  4. 付费三样按"真人自己录"做建议：是。
