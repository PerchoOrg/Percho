入口在哪、管理界面什么样、怎么新建一个小区

前两版只画了"上传之后"，没画 agent 从哪进来、管理自己影片的页面，也默认小区已经在我们库里。这一版只回答这三件事。

全部画成手机浏览器里的网页，因为素材都在 agent 的手机上；电脑上是同一套页面。界面文字是英文。图取自 Edinburgh 的影片，小区名、人名、数字都是示意。橙色虚线框是新增的东西。

你已经定的：没片的小区用 agent 的片；他的链接在 app 里放他的版本；首页卡上署名；素材进素材库、每人每小区一部、头一批人工看。

你新加的：照片、动态头像视频、用 agent 自己的声音配旁白，这三样是付费功能。画在第四节。

1入口：一个网址，三条路通到它

入口就是一个网址 percho.co/film（名字是我提的，可以改）。Agent 登录后看到的就是第二节的管理页。三条路通到这里：

  1. 直接发网址。我们找 agent 谈的时候给的就是这个。
  2. App 的 You 页多一行 "Are you an agent?"，点了在 app 里打开这个网页。
  3. 每一部 agent 影片的分享页底下有一行 "Make a film of your neighbourhood"，别的 agent 看到同行的片就能点进来。

3新建：先传素材，小区由我们认出来

Agent 不用先在两万多个小区里找。点 New film 直接选照片和视频，我们从照片自带的拍摄位置认出这是哪个小区，他只要点一下确认。认不出来或者库里没有，他打个名字、在地图上点个位置，小区就建好了。

第二步，认不出来时：打名字，从建议里选；库里没有就新建，只要名字和地图上一个点。

为什么能认出来：手机拍的照片和视频里带着拍摄地点，我们库里的小区已经有边界或位置（给房源配小区用的就是这个）。

还没验证的一点：iPhone 的浏览器在选照片时会不会把拍摄地点一起交给网页，我要在真机上试过才能确定。交不出来的话，这一步就改成用手机当前位置。

认不出来的情况：从微信之类转存过的照片会丢掉地点。这时用手机当前位置，再不行就是右边那屏。

新建的小区不会马上出现在 app 里，要等片子我们看过才一起上线，重名的会提示他是不是同一个。

顺带的好处：拍摄地点也能用来确认"至少有一张是在小区里面拍的"。

我对这三样的理解，你看对不对：

照片：他的头像，出现在名片上和片尾。

动态头像视频：他自己录的几秒钟真人小视频，在名片上循环播放。不是 AI 生成的数字人。

自己的声音：我们把这部片的旁白稿给他，他在手机上一句一句念，录下来替换掉合成的旁白。不是用 AI 克隆他的声音。这样不用接新的付费服务，也不占我们每天 100 句的旁白额度。

收费：后台的付费功能（按月的 Partner）之前已经做好但没打开，还差你的 Stripe 账号。

需要你定

  1. 入口是一个单独的网址，手机浏览器优先建议：是。不用等 app 审核，agent 也不用装东西。App 的 You 页加一行通到它。
  2. 新建的方式：先传素材，由拍摄地点认小区，认不出再打名字建议：是。
  3. 付费三样按上面的理解做（真人小视频，自己念稿）如果你要的是 AI 数字人或者 AI 克隆声音，告诉我，那是要另外接付费服务的，我先报价。
  4. 网址叫 percho.co/film或者你给个名字。

回 「都按建议」，或者告诉我哪一条要改。
