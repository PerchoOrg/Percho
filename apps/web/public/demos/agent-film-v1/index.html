Agent 上传素材，生成自己的小区影片

按你定的三条：先做 agent、每人一部自己的版本、照片和视频都收。下面是 agent 在网页后台会看到的四步，然后是买家看到什么，最后是四件要你定的事。

画面里的界面文字是英文（后台本来就是英文）。示意用的图取自现在这部 Harvest Park 影片，agent 的名字是编的。橙色虚线框是新增的东西，真实页面里没有虚线。

入口在哪：后台的小区页，现有的 Media 旁边多一个 My film。只改网页，不需要发新的 iOS 版本。

1上传素材

Agent 把手机里的小区照片和视频拖进来，勾一次授权。每一件素材自动检查，结果只有两种：Ready（能用），或者 Not used 加一句大白话的原因。

Make my film

会被拒的：有人脸、宠物、单独一栋房子或室内、模糊、泳池盖着冬罩。这些就是现在我人工把关的那几条，这里改成自动判断。

MLS 挂牌照片不收：FMLS 的许可只管 percho.co 上的房源展示，不包括做影片。

2视频怎么用

Agent 传的是一整段手机视频。Percho 从里面挑最多四段稳的、3 到 5 秒的画面，亮着的就是挑中的。Agent 可以取消某一段，第一版不提供手动剪。视频原声不用，影片还是旁白加音乐。

飞轮在哪

Agent 传的素材除了进他自己的版本，也进 Percho 这个小区的素材库。所以每多一个 agent 上传，app 里那部公共影片也能重剪得更好，片尾署他的名。Agent 得到一部能获客的片子和线索，我们得到最缺的小区内部素材。

需要你定四件事

  1. App 里放谁的片建议：app 保持 Percho 的公共影片，agent 的版本只在他自己的链接上。
  2. Agent 的素材要不要也进公共影片建议：要，并在片尾署名。上传时的授权条款会写明这一点。
  3. 免费给多少建议：每个 agent 每个小区一部；补了新素材才能重剪，一天最多一次。旁白一天只有 100 句的额度，大约够 6 到 8 部片，所以要排队。
  4. 头一批要不要人工看建议：要。素材能不能用由程序判断，但头一批成片在链接生效前由我们看一遍。

回 「都按建议」，或者告诉我哪一条要改。定了之后先做照片这条线，再做视频。
